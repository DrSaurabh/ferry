# Ferry 2.1 — Log events and intent → outcome catalogue

Written first in Ph11a (plan CP107, §2.1; design §7.1 + M8, M18). Machine-readable: `tools/review_logs.py`
and the JVM test `EventCatalogueTest` parse the three tables between the HTML comment markers. Every later
phase only **adds** rows (and removes the events it now emits from `EventCatalogueTest.PENDING`).

Line format (phone and TV, plan §2.2):

```
2026-11-24 02:01:03.456 #1234 s=7f3a tap id=send screen=picker
```

Local time · `#seq` (monotonic across restarts) · `s=` session id (4 hex, per process start) · event name ·
`key=value` fields (value quoted when it contains a space, `"`, `=` or is empty; `"`→`\"`, `\`→`\\`, newline→`\n`).
The PC's own `ferry-log.txt` keeps its 2.0 tab-separated format.

## 1. Events

`layouts`: `phone`, `tv` or `both` (where the event is written). `fields`: the fields the event carries
(comma-separated; `?` = optional). `level`: `N` = written at Normal and Detailed, `D` = Detailed only.

## 2. Intents and expected outcomes (G1, G9)

Syntax: `event [field=value]…`; alternatives separated by `\|`; `(TV)` / `(PC)` = the line must come from that
device kind; `within_s` = time limit (`-` = none, the outcome only has to come before the next `app.start`);
`key` = the field that pairs intent and outcome (`-` = next matching line of the same device).

## 3. Distress signals (L6, G1–G11)

<!-- signals:start -->
| rule | L6 text | parameters |
|---|---|---|
| G1 | action started with no result | outcomes table (part 2) |
| G2 | same button ≥ 3× within 5 s | tap id same; count=3; window_s=5 |
| G3 | screen A → B → A within 10 s | screen name; window_s=10 |
| G4 | same dialog / error twice in a row | dialog name or err.shown text; consecutive=2 |
| G5 | Back that discarded picks | back result=discarded_picks |
| G6 | app killed mid-task | app.start exit≠user while the previous process had send.start or play open; app.bg during a send/cast is only counted in the daily summary |
| G7 | video stopped < 10 s after start | play event=stop\|back; after=first_frame; window_s=10 |
| G8 | waits > 30 s | send.wait lasting; min_s=30 |
| G9 | controller command without TV acknowledgement | O3, O4 failures |
| G10 | permission refusals | perm result=denied |
| G11 | every "Something's wrong" marker | wrong; context_s=30 |
<!-- signals:end -->
