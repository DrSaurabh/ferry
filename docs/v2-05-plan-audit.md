## Result

## Deferred items and destinations

- **PR7 (part)**: a second small video fixture written without `+faststart` (index at the end), to exercise seeking on such files → implementation, Ph8b, only if `TvLongPauseTest`'s seeks pass and time allows; real files of that kind are covered by acceptance 5 on the stick.
- **PR13 (part)**: `ubuntu-22.04` (the Python 3.8 job) will be retired by GitHub at some point → maintenance note in the Ph10 handoff; switch that job to whatever image still offers 3.8, or to Windows only.
- **PA16 (part)**: emulator `ram-size` → Ph0b, only if the TV image proves too slow.
- **PA13 (rest)**: removing the API 25–28 thumbnail and permission branches, and `desugar_jdk_libs` → v2.1, together with any decision to raise minSdk (H5).
- **PR3**: the true API level of `MediaStore.getMediaUri` → settled by lint `NewApi` in Ph5b; the result goes into `docs/v2-progress.md`.

Nothing here changes an agreed requirement. Two decisions deserve the user's eye at review because they narrow what the design promised: **H31** (no outbox download on Android 9 and older; the phone is Android 15 and the TV never downloads to Downloads) and **H30** (the PC now refuses an upload early when the disk is nearly full).
