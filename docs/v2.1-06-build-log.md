### Decisions
- **B101** `migrate_old_logs(data_dir, note)` returns the folder the request log uses: `logs/`, or the data folder
  itself when a move fails ("keep the old place", one console note). A `logs/ferry-log.txt` that already exists is
  never overwritten (the old file then stays where it was).
- **B102** `DeviceLogStore`: device id must be 1–16 hex chars, otherwise `unknown/`; folder = `sanitize_name("<name>
  (<id>)", dest_dir=logs)` and must resolve directly under `logs/` (else `unknown/`). Lines whose `#seq` ≤ the stored
  last are dropped; lines without a seq (e.g. `gap`) are kept unless `X-Ferry-Log-From` ≤ last (a repeated body).
  Cap sweep: rotated files (`*.1.*`) oldest first, then other devices' current files; never `*.zip`, `ferry-log.txt`,
  `.last-seq` or the file just written.
- **B103** `POST /api/v1/logs` answers 400 to an empty body (no newline), 411 without Content-Length (same as
  check-batch); request-log outcome `log N lines`; no console line (would be noise every 10 min).
- **B104** `verify_inbox.py device-log` takes `--logs <PC data>/logs --expect ev1,ev2 [--device substr]`; the suite
  helper is `check_device_log <PC> <events>` (the plan's `--pc T` wording maps to this helper).
- **B105** `tools/tests/test_placeholder.py` is not empty (pytest exits 5 on "no tests"): it checks that the
  catalogue's three tables parse (same split rule as `EventCatalogueTest`).
- Step 2 (`:core`): `log/EventLog.kt` (+ `Detail`), `log/LogStateStore.kt`, `log/LogReader.kt` (+ `LogChunk`),
  `FerryApi.postLogs` (interface default = `LogsUnsupported`, so test fakes need no change) + `FerryClient.postLogs`,
  `FerryException.LogsUnsupported`, `FerryHttp.newClient(…, deviceId, deviceType)` headers (null = left out; the app
  passes them from Ph11b, when `Prefs.installId` exists), `PcInfo.timeMs`, `LogsReply`. Tests `EventLogTest`,
  `LogReaderTest`, `it/OldPcLogsTest`, `it/LogsAgainstFerryPyTest`; `it/FerryPcProcess.log` → `data/logs/ferry-log.txt`
  (adapted: CP110 path).
- **B106** `RingLog` stays unchanged in Ph11a (the app still writes through it until Ph11b swaps in `EventLog`;
  its tests stay). Ph11b decides whether to delete it (plan §1.2 "agent's choice").
- **B107** `EventLog` tail (`snapshot()`, PS3): values unescaped; a `diag` line reads `… diag <tag> <msg>` like 2.0's
  `RingLog` line, so 2.0 androidTests such as `SendHelpers.finishedRuns()` (`contains(" engine finished:")`) keep
  matching. The file line is always the escaped §2.2 format. Values are also quoted when they contain `\`, tab or CR
  (escaped `\\`, `\t`, `\r`) so they parse back. Bad event/field names are lower-cased and `_`-replaced, never thrown.
- **B108** `gap` line (M8) = `<time of the oldest line> #- s=---- gap from=<a> to=<b>`; `X-Ferry-Log-From` is the
  first real seq of the body. Also emitted when the cursor is 0 and the oldest kept line is > 1.
- **B109** `LogStateStore` JSON keys exactly `seq`, `shippedSeq`, `session` (plan §1.2); file `ferry-log-state.json`.

### Decisions
- **B111** The event log lives in `files/logs/` (`ferry-app-log.txt`, `.1.txt`, `ferry-log-state.json`), the 2.0 log
  folder, not `files/` as plan §2.2 says: the FileProvider path `logs/` for "Share diagnostics log" stays as it is.
  2.0 lines in the old file have no `#seq` and are skipped by `LogReader` (Ph11a).
- **B112** `RingLog` and `RingLogTest` are deleted (B106: Ph11b decides); `AppGraph.ringLog` is a getter returning
  the `EventLog` (`snapshot()`, `previousFile`, `file`), so the 2.0 androidTests compile unchanged.
- **B113** Tap helpers = `onClickLogged(id) { … }` (plain function returning the click lambda, usable for every
  `Button`/`TextButton`/`Tab`/`FilterChip`/`DropdownMenuItem`/`clickable`), `TapLog.tap(id)`, `tvClickable(id = …)`
  (id is the new first parameter), `LogDialog(name)`/`logDialog(name, choice)`, `LogError(text)` (`err.shown`),
  `LogScreen(name)`. No `Modifier.logTap`/`LoggedButton`: `onClickLogged` covers them. `tap` lines carry
  `screen=<top Navigator screen>` (`TapLog.screen`). Ids are `<screen>.<what>` except the catalogue's intent ids:
  picker Send = `send`, picker Play on TV = `cast` (O1, O6); `tv` arrives with the TV button (Ph18).
- **B114** `TapIdLintTest` rule (CP111): every non-import line in `ui/**/*.kt` with `onClick =`, `.clickable`,
  `.tvClickable(`, `onCheckedChange =`, `combinedClickable` or `onLongClick =` must contain `onClickLogged(`,
  `TapLog.tap(`, `tvClickable(id = ` or `// tap-id: <id>`. Picker cell selection (`toggleable`) is not a tap id:
  the count is logged by `pick` at Send.
- **B115** Flag fields use `1`: `dialog name= shown=1` then `dialog name= choice=…`; `perm name=media ask=1` then
  `perm name=media result=full|partial|denied`; `notif name=results posted=1`; `notif name=<open> tapped=1 action=open|retry`.
- **B116** `SendEvents` (app `log/`): one 4-hex batch id per engine; `send.start` per add (files added to a running
  engine log another `send.start` with the same batch); `send.item` once per file reaching a final state
  (`saved`, `saved_renamed`, `already_on_pc`, `failed_<reason>`, `cancelled`, `not_sent_<reason>`; again after
  Retry/Send anyway); `send.wait reason=pc_not_found` on entering WaitingForPc; on Finished `send.cancel` (stop =
  Cancelled) or `send.done sent= skipped= failed= ms=`; then `LogShipper.afterSend()`.
- **B117** `app.start` also carries `model=` (catalogue part 1 field list gains `model?`); `exit=unknown` below API 30
  or without a record; `app.stop reason=finish` when `MainActivity` finishes (Back on the root screen); `app.fg/bg`
  from a started-activity counter that ignores configuration changes.
- **B118** `DeviceNames.choose` sources `override|system|model|fallback`; the maker is not doubled when the model
  already starts with it; no maker/model → `Android <id>`; the TV ignores the phone-only override. Resolved at start,
  `MainActivity` create/start and after a rename; `NetworkBinder` rebuilds its client when name/id/type change.
- **B119** `LogShipper`: a round posts chunks until nothing is left (≤ 20); a trigger during a round runs one more
  round; `lastShipMs` is set when a round starts (an empty log does not ship on every PC call); timeouts 5 s at
  background, 30 s otherwise; `clock peer=pc` is logged only when the offset moved by > 1 s (from `/info` and the logs
  reply). Triggers: `app.bg`, send end, successful locate (`/info`) and outbox listing.
- **B120** `Prefs.clear()` (tests) keeps `installId`: it names the install (PC log folder), it is not a setting.
- **B121** `EventCatalogueTest.PENDING` after Ph11b: `share.resolve` (Ph14); `send.queued`, `send.resume`,
  `work.run` (Ph15); `ctl.rx`, `caps`, `volume` (Ph16); `zoom` (Ph17a); `doc` (Ph17b); `ctl.tx`, `ctl.ack`,
